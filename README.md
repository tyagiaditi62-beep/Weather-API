# Weather API

A web application that lets users to search for a city and view
its current weather information using a weather API.

## Features

- Search weather by city name
- Displays temperature
- Displays weather icon and description
- Displays humidity
- Displays wind speed
- Displays feels-like temperature
- Displays atmospheric pressure
- Displays visibility
- Displays minimum and maximum temperature
- Loading and error messages
- Clear search option

## Technologies Used

- HTML
- CSS
- JavaScript
- Weather API

## How It Works

The user enters a city name and clicks the Search button.
The application sends a request to the weather API and displays
the weather information returned by the API.

## How to Run

Open `index.html` in a web browser.
